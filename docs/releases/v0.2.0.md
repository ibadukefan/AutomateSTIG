# AutomateSTIG v0.2.0 — legacy application

> **Legacy release:** `v0.2.0` predates the scanner-first AutomateSTIG product
> boundary. It does not contain the difficult-device scanner workflow, current
> sparse handoff, unified verified installer, or release-integrity contract
> documented on the scanner-first development branch.

The historical assets are retained so existing users can identify and recover
old installations. They include platforms and packaging that are not part of
the current support boundary. In particular, do not treat the presence of a
Windows, AppImage, DMG, or other `v0.2.0` asset as a current support claim.

Do not install this release for a new scanner deployment. Wait for an approved
scanner-first `v0.3.x` release or use an explicitly reviewed source commit in a
controlled pilot. Review the repository
[README](https://github.com/ibadukefan/AutomateSTIG#readme),
[Quickstart](https://github.com/ibadukefan/AutomateSTIG/blob/main/docs/quickstart.md),
and [Security Policy](https://github.com/ibadukefan/AutomateSTIG/security/policy)
for the current status and boundaries.
