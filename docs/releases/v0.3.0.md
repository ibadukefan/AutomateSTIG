# AutomateSTIG v0.3.0 — difficult-device scanner pilot

This release establishes the scanner-first AutomateSTIG pilot. It supplements
STIG Manager with deterministic collection, evaluation, and verified sparse
handoffs for three difficult-device profiles. STIG Manager remains the system
of record for assets, assignments, human review, findings, approvals,
dashboards, reports, and history.

## Supported pilot profiles

| Target | Exact STIG | Automated | Manual | Full benchmark |
| --- | --- | ---: | ---: | ---: |
| NetApp ONTAP 9.x | ONTAP DSC STIG V2R4 | 15 | 7 | 29 |
| FreeBSD 13–14 | GPOS V3R3 | 6 | 24 | 203 |
| Cisco IOS-XE 17 | Router NDM STIG V3R7 | 33 | 9 | 42 |

The profiles are experimental. These counts describe scanner coverage, not a
compliance score or a claim of complete benchmark automation.

## Install

Use the exact version approved by the site on macOS or GNU/Linux:

```bash
version=v0.3.0
gh release verify "$version" --repo ibadukefan/AutomateSTIG
gh release download "$version" --repo ibadukefan/AutomateSTIG \
  --pattern install.sh --output automatestig-install.sh
sh ./automatestig-install.sh --version "$version"
```

The installer is noninteractive, tag-bound, checksum- and Sigstore-verifying,
transactional, user-local, and launches the localhost GUI. It does not use
`sudo` or alter shell profiles. Windows deployment is unsupported. A complete
minimum macOS and GNU/Linux compatibility matrix is not yet published.

## Workflow and exports

- Learn the results screen safely with **Open sample result**.
- Run disconnected by default; STIG Manager and remote SSH are explicit
  connected operations.
- Download one complete selected-run ZIP containing sparse reviews, XCCDF 1.2,
  CKLB, the native result, retained evidence/provenance, a canonical run
  request, and an integrity manifest.
- Verify the handoff with `automatestig scanner verify-handoff` before an
  approved receiver reconciles only the sparse reviews with the exact existing
  STIG Manager assignment.

AutomateSTIG does not ship changed-review writes, asset management, assignment
management, human finding edits, remediation, dashboards, or portfolio
reporting.

## Security and known limits

- Missing, denied, timed-out, truncated, malformed, ambiguous, stale, or
  unsupported evidence fails closed.
- Connected mode accepts only the retained tested STIG Manager build
  `1.6.13+1`.
- macOS binaries are not notarized; use the site's approved Gatekeeper process.
- Producer authenticity requires the protected detached-signature workflow or
  an independently authenticated transfer. Unsigned handoff verification proves
  internal integrity, not producer identity.
- Live-device, receiver, signing, and first-use evidence named in the release
  gate remains the authority for deployment approval.
