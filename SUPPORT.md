# Support

AutomateSTIG is currently an experimental difficult-device scanner pilot.

## Start here

- Installation or first scan: [Quickstart](docs/quickstart.md)
- Installation failures: [Installation](docs/installation.md)
- Scanner errors: [Troubleshooting](docs/troubleshooting.md)
- Exact supported targets and revisions: [Supported Targets](docs/supported-targets.md)
- Product status and limitations: [README](README.md)

## Ask for help

Use the repository's guided issue forms:

- **Installation or first-run help** for setup and launch problems;
- **Scanner bug** for collection, evaluation, evidence, handoff, or GUI defects;
- **Difficult-device target request** for a target backed by real analyst pain
  and available validation resources.

Never attach operational evidence, device configurations, credentials, tokens,
private keys, or controlled data to a public issue. Use
[private vulnerability reporting](https://github.com/ibadukefan/AutomateSTIG/security/advisories/new)
for suspected security defects.

STIG Manager owns assets, assignments, human findings, review workflow,
dashboards, and reporting. Request those features from the
[STIG Manager project](https://github.com/NUWCDIVNPT/stig-manager/issues).

## Support boundary

The three bundled scanner profiles remain experimental until their live-device,
receiver, signing, and first-use gates pass. A successful synthetic run or CI
job is not a production-support claim. See
[Supported Targets](docs/supported-targets.md) for the exact boundary.
